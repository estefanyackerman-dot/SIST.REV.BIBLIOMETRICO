# Plantilla de criterios de inclusión y rechazo para título y resumen

## Propósito
Use esta matriz para decidir si cada registro debe continuar al cribado por título y abstract. La revisión se hace en dos pasos: título y resumen.

## Fila de revisión
- Registro / DOI
- Fuente
- Título
- Año
- Evaluador
- Decisión inicial: incluir / excluir / revisar
- Justificación breve

## Criterios de inclusión

### Para título
- El título menciona psilocybin, psilocin, Psilocybe, o un tratamiento basado en psilocibina.
- El título sugiere una intervención, ensayo clínico, revisión, estudio preclínico, farmacología, biosíntesis, o evaluación terapéutica.
- El título está en español, inglés u otro idioma elegible del área de interés, siempre que el tema sea identificable.

### Para abstract
- El abstract describe un estudio o revisión sobre psilocybin/psilocin en humanos, animales, cultivos, biosíntesis o farmacología.
- El abstract presenta población, intervención, resultados o síntesis relevante para depression, anxiety, MDD, TRD, suicidality, cancer, PTSD, OCD, bipolarity, alcohol, pain, o estudios básicos del mecanismo.
- El abstract reporta datos clínicos, preclínicos, farmacológicos, metodológicos o de seguridad suficientes para catalogar el artículo.

## Criterios de exclusión

### Por título
- El título apenas menciona psilocybin sin describir un estudio o revisión relevante (p. ej., editorial, noticia, comentario, blog, nota de prensa).
- El título se refiere a otros psicodélicos o compuestos que no son psilocybin/psilocin y no permite una relación temáticamente cercana.
- El título es claramente una errata, comentario, corrigenda o expresión de preocupación sin evidencia de estudio nuevo.

### Por abstract
- El abstract no describe población ni intervención ni resultados relevantes para el objetivo del corpus.
- El abstract describe una publicación que no es de investigación (comentario, carta editorial, erratum, corrección, lenguaje de prensa).
- El abstract está totalmente vacío, no reporta metodología ni resultados, o es irrelevante para la pregunta.
- El abstract se centra en otro medicamento o compuesto sin conexión suficiente con psilocybin.

## Regla de decisión

1. Si el título es claramente no relacionado, excluir directamente.
2. Si el título es compatible pero el abstract es insuficiente, pasar a revisar otro campo o a pleno texto.
3. Si el título y el abstract son compatibles con psilocybin y una pregunta relevante, incluir para extracción.
