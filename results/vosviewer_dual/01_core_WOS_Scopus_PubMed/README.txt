Updated bibliometric corpus based on searches run on 5 September 2026.

Corpus: 2,128 unique documents from Web of Science Core Collection, Scopus
and PubMed. The 3,822 source records were deduplicated first by normalized
DOI and then by normalized title. The WOS export supplied 1,837 unique
records after internal deduplication.

Open the *_map.txt and *_network.net files in VOSviewer using Create map from
network data. Node weight is document frequency and edge weight is
co-occurrence frequency. The corpus, annual production and source counts are
included in this folder.
